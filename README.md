# Shadrack Baraka Mwahanga · Portfolio

Field-notebook portfolio site. Constraint is the brief.

**Live:** https://shadrack-portfolio-alpha.vercel.app

## What it is

Single-page case file: about, shipping log, selected systems, lab link, credentials, contact. Same brand as the GitHub profile and Shadrack Lab (paper, ink, red pen, stamps). No particle hero, no neon cards.

## Stack

One HTML file. System fonts. CSS pen-draw and stamp motion (respects `prefers-reduced-motion`). Badge reel video + certificate scan.
