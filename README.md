# Shadrack Baraka Mwahanga · Portfolio

<img src="https://raw.githubusercontent.com/shadrackb1/shadrackb1/main/systems-map.svg" width="100%" alt="Systems map" />

Personal site for Shadrack Baraka Mwahanga — engineer and law student at Kabarak University. Content tracks the GitHub profile: offline AI, legal tech, field systems built for Kenyan constraints.

**Live:** https://shadrack-portfolio-alpha.vercel.app

**Hard constraint it answers:** one page a recruiter or judge can open on a phone in under a minute, with no build step and no third-party runtime beyond fonts. Dark theme, particle hero, scroll reveals, count-up stats, and the real project list.

## Stack

Single HTML file. No build step, no framework, no bundler. Canvas particle network for the hero, IntersectionObserver for scroll reveals, CSS custom properties for the theme. CV and certifications ship as markdown beside the page (`cv.md`, `certifications.md`).

## Run locally

Open `index.html` in a browser. That is the whole deploy.

```bash
# optional static server
npx serve .
```
